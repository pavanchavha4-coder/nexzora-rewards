# NEXZORA REWARDS

A mobile-first prototype for a sponsored campaign rewards app.

## Current prototype features
- Home dashboard and featured campaign cards
- Watch tab with demo campaign completion
- Demo coin wallet
- UPI withdrawal preview (does not submit payments)
- Referral and profile screens

## Important
This is a UI prototype only. Campaigns are sample content, demo coins have no cash value, and no real ads, user accounts, referrals, or payouts are connected. Before launch, add sponsor agreements, approved campaign tracking, authentication, server-side reward validation, fraud prevention, privacy policy, applicable legal/tax review, and a secure payout provider.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
